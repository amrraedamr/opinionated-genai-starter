      Guardrails
      
          
      Each probe runs in a fresh conversation, so the result is not coloured by earlier turns.
      
        
      
        
      
          
      
            
      PII redaction
      
            
      Your email and card number are redacted before the model sees them, so it can only repeat the placeholders.
      
            
            
      
          
      
          
      
            
      Moderation
      
            
      Text the moderation model scores above the threshold is refused before any model call.
      
            
            
      
          
      
          
      
            
      Streamed output
      
            
      Asks the model to write a card number back. The stream holds a short tail and redacts it before it reaches you.
      
            
            
      
          
      
          
      
            
      Hostile tool result
      
            
      Tool results are checked for injection before the model reads them. This has mcp_server's echo tool hand back an injection phrase.
